# PC/Laptop/Smartphone Сервис

Едноставна статична landing страница за сервис за поправка на компјутери, лаптопи и паметни телефони.

## Подготовка за GitHub
1. Додајте `index.html` и `styles.css` во коренот на репозиториумот.
2. Иницијализирајте git репозиториум ако е потребно:
   - `git init`
   - `git add .`
   - `git commit -m "Initial site upload"`
3. Качете го на GitHub и активирајте GitHub Pages на главната гранка (`main`, `master` или `gh-pages`).

## Безбедност
- GitHub Pages автоматски користи HTTPS.
- Производете ја страницата како статична и не додавајте надворешни скрипти без потреба.
- Ако во иднина додадете форми, секогаш користете HTTPS и валидација на податоци.
